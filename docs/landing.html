What BITFIRST is

A fixed-supply BEP-20 token. The entire supply is minted once in the constructor — there is no owner mint, no pause switch, no blacklist and no transfer tax. Six wallets receive the supply at deployment, and two of them are lock contracts, so the release schedule is enforced by code and visible on-chain instead of resting on a promise.

How the member app works

One self-contained file, about 70 KB. It needs no server, no internet, no email and no fee — everything stays in the phone's localStorage.

1  Grand Welcome

A landing screen explains the project before anyone logs in.

2  Owner login

The owner signs in with the username Owner (or 0) and a password they set themselves on first run. No password ships inside the app.

3  Member joins

A member registers, the owner approves, and the member receives 3,690 ¥. Tokens stay locked for 180 days.

4  Recovery

A security question resets a forgotten password — no email required. Every password box has a show/hide toggle.
