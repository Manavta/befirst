Member login

Members can enter their number (e.g. 1) or email (e.g. ram@example.com). For the owner, type Owner (or 0).

Never enter a private key or seed phrase in this box — the app rejects such input automatically.

Create new member

Fill the form → the owner approves → then your number and tokens are set. No fee, no money.

Never enter a private key or seed phrase. Enter only your wallet address, never a key.

Forgot password

Step 1 \u2014 enter your member number or email.

Step 2 \u2014 answer your security question

No security question on your account? Then only the owner can set a new password \u2014 admin panel \u2192 tap your member \u2192 Set new password. This app has no email server, so an emailed reset link is not possible.
